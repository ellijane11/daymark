# Daymark

A retro-styled study streak tracker that runs entirely in your browser.

- **Tasks** with a habit-style streak grid per task (tap a day to tick it)
- **Built-in timer** with a growing pixel plant; sessions record what you studied and from when to when
- **Day view** with total time studied, per-task breakdown and session log
- **Plans** for the week, the month or any date: drag them onto a day to turn them into daily tasks
- **Notes** after each session or task completion

Everything is saved locally in your browser (`localStorage`). Use the export/import buttons for backups.
