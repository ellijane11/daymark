# Daymark

A clean study streak tracker that runs entirely in your browser. Light and dark themes in a green, blue and gold palette.

- **Today page:** pick the tasks you're doing today and see a dated streak calendar for each one
- **Streak grids:** tap today or yesterday to tick it and add a note (older days are locked)
- **Built-in timer** with a growing pixel plant; sessions record what you studied and from when to when
- **Tasks page:** create any number of tasks, with optional weekly, monthly or dated plans
- **Notes** after each session, task tick or grid tap, all on the Today page

Everything is saved locally in your browser (`localStorage`). Use Export / Import for backups.
